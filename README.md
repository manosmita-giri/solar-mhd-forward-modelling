# Forward Modelling of Hα Line-Wing Diagnostics from Radiative MHD Simulation Data

## Overview

This repository documents my ongoing master's thesis project at the Indian Institute of Astrophysics (IIA), undertaken as part of my BS-MS Physics degree at IISER Berhampur.

The project investigates Hα line-wing diagnostics using radiative magnetohydrodynamic (MHD) simulation data, with an emphasis on computational analysis and radiative-transfer-based forward modelling.

## Research objectives

- Analyse radiative MHD simulation data relevant to solar-atmosphere dynamics.
- Investigate optical-depth structures and the formation of Hα line-wing diagnostics.
- Examine the relationship between velocity, thermodynamic variables, and diagnostic features.
- Develop Python-based analysis and scientific visualisation workflows.

## Methods and tools

- Python
- NumPy and Matplotlib
- MHD simulation-data analysis
- Radiative-transfer diagnostics
- Scientific plotting and visualisation
- Linux command-line workflows

## Project status

Ongoing master's thesis research.

## Research integrity and data availability

This repository is intended to document the project and share approved, reproducible code and analysis. Simulation data, unpublished results, and thesis material will be added only when their release is permitted by the relevant supervisor and data-use requirements.
