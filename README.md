# Solar MHD Forward Modelling

## Overview
This project focuses on Python-based analysis and forward modelling of radiative magnetohydrodynamic (MHD) simulation data, with applications to solar atmospheric diagnostics.

## Research Interests
- Solar physics and solar atmospheric dynamics
- Radiative MHD simulations
- H-alpha line-wing diagnostics
- Optical-depth analysis
- Scientific data visualisation

## Tools and Technologies
- Python
- NumPy
- Matplotlib
- Scientific data analysis

## Project Goals
- Analyse physical variables from MHD simulation data.
- Explore optical-depth structures and atmospheric diagnostics.
- Develop reproducible workflows for scientific analysis and visualisation.

## Current Status
Project documentation and code will be added as they are prepared and approved for sharing.
